# Personal Portfolio Website

A complete responsive portfolio inspired by the supplied reference video.

## Features
- Home / About / Projects / Contact sections
- Red neon dark design with light-theme option
- Upload your own DP/profile image
- Edit name, role, bio, about details, stats, contact information
- Add/remove/edit projects
- Add project image URLs
- GitHub, LinkedIn and Instagram links
- Mobile responsive navigation
- Smooth reveal animations and floating visual elements
- All edits persist in the browser with localStorage
- No backend required

## Run
Open `index.html` in a browser.

For the best local development experience, use VS Code + Live Server.

## Customize
Click **Edit Profile** on the website. Upload your image and enter your own details, then click **Save Changes**.

Note: uploaded images are stored in browser localStorage, so clearing browser site data resets them.
